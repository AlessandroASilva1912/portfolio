Agendamento de serviços

AgendaSystem

Sistema de agendamento para serviços com ASP.NET Core MVC, Entity Framework Core e SQLite. Permite organizar profissionais, serviços e clientes, com acesso separado para administração e clientes.

Regra de negócio em destaque: verifica sobreposição de horários por profissional e considera a duração do serviço e o expediente antes de aceitar um agendamento.

Cenário de teste proposto
Com uma reserva das 9h às 10h, tentar agendar o mesmo profissional às 9h30. O sistema deve recusar o conflito e preservar a reserva original.

C# / ASP.NET Core Entity Framework Core SQLite Identity

Operações industriais

OS Manager

Sistema completo de gerenciamento de Ordens de Serviço para ambientes industriais, com dashboard em tempo real, histórico por máquina, atribuição de responsáveis e exportação de relatórios em Excel.

Cenário de teste proposto
Criar a primeira ordem de serviço em uma base vazia. Conferir se a ordem aparece na lista com a máquina correta e se o total do painel passa de zero para um.

Autenticação em duas etapas

SecureAuth MFA

Sistema de autenticação multi-fator (MFA) para aplicações web, com fluxo de login em 2 etapas, geração de QR Code via TOTP (RFC 6238), códigos de backup, rate limiting por IP e dashboard de segurança. Algoritmo TOTP implementado do zero sem bibliotecas externas.

Cenário de teste proposto
Informar a senha correta e um código de verificação expirado. O acesso deve continuar bloqueado até a conclusão da segunda etapa com um código válido.

Python / Flask SQLite HTML · CSS · JS TOTP · RFC 6238

Gestão de estoque

StockPro

Aplicação web full-stack desenvolvida com Python/Flask e SQLite, sem dependências externas de frontend. Possui tela de login com cadastro de usuários, dashboard com KPIs e gráficos, cadastro de produtos e fornecedores, controle de entradas e saídas com histórico, alertas automáticos de estoque mínimo, relatórios por período e sistema de permissões com três perfis (Admin, Gerente e Operador). Interface SPA responsiva com tema escuro, ícones SVG inline e sem nenhum framework JavaScript.

Cenário de teste proposto
Registrar uma entrada de três unidades para um item com saldo de cinco. Conferir se o saldo passa a oito e se a movimentação corresponde à entrada registrada.

Python / Flask SQLite HTML · CSS · JS Chart.js REST API
