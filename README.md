## Projetos em destaque

- [AgendaSystem](https://github.com/AlessandroASilva1912/AgendaSystem): agendamento com ASP.NET Core MVC, permissões por perfil e validação de conflitos.
- [OS Manager](https://github.com/AlessandroASilva1912/OS-Manager-Sistema-de-Ordens-de-Servi-o): gestão de ordens de serviço com Flask e SQLite.
- [StockPro](https://github.com/AlessandroASilva1912/Gest-o_de_Estoque): controle de estoque, movimentações e relatórios.

## Executar localmente

Clone este repositório e abra `index.html` no navegador. Para servir os arquivos via HTTP, execute `python -m http.server 8000` na raiz e acesse http://localhost:8000.
